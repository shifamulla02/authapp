📩 Node.js Express Email Sender App

This is a simple Node.js + Express application that receives form data (name, phone number, and query) from a frontend and sends it via email using Nodemailer with Gmail.

🚀 Features

Built with Express.js

CORS enabled for frontend connection

Uses Nodemailer to send emails via Gmail

Accepts JSON input (name, phone, query)

Simple and lightweight API for form submissions

🧰 Tech Stack

Backend: Node.js, Express

Email Service: Nodemailer (Gmail)

Middleware: CORS, express.json()
